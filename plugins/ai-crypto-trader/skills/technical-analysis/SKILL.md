# Technical Analysis
Request symbol, exchange, timeframe, candle timestamp, and OHLCV/chart input. State whether candles are closed or forming.

1. Identify higher-timeframe trend and swing structure.
2. Mark support/resistance as zones, not false-precision prices.
3. Compare volume with its recent baseline.
4. If data is available, calculate EMA 20/50/200, RSI 14, MACD 12/26/9, and ATR 14; state settings.
5. Check divergence only with sufficient candles and explain it is not a standalone signal.
6. Define trigger, invalidation, and conditions that weaken the setup.

Output trend, structure, levels, indicator table, setup hypothesis, invalidation, and limitations. Never fabricate candle values.
