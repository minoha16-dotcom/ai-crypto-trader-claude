# Spot Trading Research
Review asset/pair, exchange liquidity, spread, volume, market structure, token risks, and proposed plan. Use timestamped data or disclose limitations. Define thesis, entry condition, invalidation/stop, target scenarios, fees/slippage, and position size via risk-management. Explain limit versus market order execution risk. Never claim to execute orders or request API keys/withdrawal access.
